# Lesson 2: Practice

**Your Assignment:**

The Land Stewards are preparing a briefing document. Help them structure it.

1.  Create a main heading: `Monitoring Update`.
2.  Create an unordered list of the key estuaries being monitored. Use the following locations:
    *   Cowichan Bay
    *   Chemainus Estuary
    *   Penelakut Island
3.  Create an ordered list for the standard survey procedure. Use the following steps:
    1.  Visual inspection of the area.
    2.  Collection of water and soil samples.
    3.  Wildlife observation and documentation.
4.  Add a concluding paragraph that includes a link. Here's the text:
    `For more detailed information on our projects, please visit the official Land Stewards website.`
    The link text should be `official Land Stewards website` and it should point to a placeholder URL: `https://www.landstewards.dev` (this is a fictional URL for the tutorial).
