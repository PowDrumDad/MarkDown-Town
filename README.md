# Welcome to the Markdown Town Tutorial!

This 8-part tutorial is designed for everyone, from absolute beginners to those looking for a refresher on Markdown. We'll take you on a journey from the very basics to more advanced topics, all while helping a fictitious environmental organization, "The Land Stewards," with their real-world documentation challenges.

## Prerequisites

- A text editor (like VS Code, Sublime Text, or even Notepad).
- A web browser to view your rendered Markdown (optional but recommended).
- A desire to learn!

## Curriculum

### Lesson 1: The Absolute Basics
- **Concept:** What is Markdown and why is it useful?
- **Syntax:** Headings (`#`), paragraphs, bold (`**`), italic (`*`).
- **Story:** Introduction to "The Land Stewards" and their mission. The first task is to create a simple report title and introduction.

### Lesson 2: Lists and Links
- **Concept:** Organizing information with ordered and unordered lists, and adding hyperlinks.
- **Syntax:** `*` or `-` for unordered lists, `1.` for ordered lists, `[text](url)` for links.
- **Story:** The Land Stewards need to list the locations they are monitoring and link to their respective pages on the organization's internal wiki.

### Lesson 3: Images and Blockquotes
- **Concept:** Embedding images and quoting text.
- **Syntax:** `![alt text](image url)`, `> quote`.
- **Story:** A report needs to include a picture of an oil sheen on the water and a quote from a concerned citizen.

### Lesson 4: Code Blocks and Horizontal Rules
- **Concept:** Displaying code snippets and separating content.
- **Syntax:** ```language ... ```, `---` or `***`.
- **Story:** The Land Stewards are starting to use Python for data analysis. You'll help format a script that calculates the area of a recent fuel spill.

### Lesson 5: Tables
- **Concept:** Creating tables to display structured data.
- **Syntax:** Using pipes (`|`) and hyphens (`-`) to create tables.
- **Story:** The Land Stewards have collected water quality data from several locations and need to present it in a clear, tabular format.

### Lesson 6: Task Lists and Strikethrough
- **Concept:** Creating checklists and indicating completed items.
- **Syntax:** `- [ ]` for an incomplete task, `- [x]` for a complete task, `~~strikethrough~~`.
- **Story:** The team needs a checklist for their equipment before heading out to survey a new estuary.

### Lesson 7: Advanced Markdown - The Python Connection
- **Concept:** Using a Python script to generate a Markdown report.
- **Syntax:** This lesson will focus on a Python script that writes a `.md` file.
- **Story:** The Land Stewards want to automate their weekly summary report. You will help create a Python script that pulls data from a simple database and generates a Markdown report.

### Lesson 8: Markdown in the Wild - Top GitHub Repositories
- **Concept:** A highlights chapter showcasing real-world usage of Markdown.
- **Content:** A curated list of 5 public GitHub repositories that make excellent use of Markdown for documentation, tutorials, or project pages.
- **Story:** To see how professionals use Markdown, you will explore some of the best examples on GitHub.

## How to Run This Tutorial (Local Version)

This tutorial is designed to be run locally on your computer.

### Prerequisites

1.  **A Code/Text Editor:** You will need a text editor that can render Markdown, like VS Code, Sublime Text, or Atom. VS Code is ideal because it has a built-in Markdown preview (`Ctrl+Shift+V`).
2.  **The Project Files:** You need a copy of the entire `MarkDown-Town` project on your computer.
3.  **Python (for Lesson 7):** To complete Lesson 7, you will need to have Python installed on your computer.

### Your Workflow

1.  **Open the Project:** Open the `MarkDown-Town` folder in your text editor.
2.  **Start with the README:** Read this `README.md` file to understand the curriculum.
3.  **Go Lesson by Lesson:** Navigate into the `Markdown-Tutorial/Lesson1` folder.
4.  **Read the Lesson:** Open and read `lesson.md` to understand the concepts for that lesson.
5.  **Do the Practice:** Open `practice.md` and attempt the exercise.
6.  **Take the Quiz:** Open `quiz.md` and answer the questions.
7.  **Check Your Work:** Finally, open `solution.md` to see the correct answers for the quiz and the recommended solution for the practice exercise.
8.  **Repeat:** Repeat this process for each lesson folder, from 1 to 8.
