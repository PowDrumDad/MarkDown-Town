# Lesson 2: Quiz Solutions

Here are the answers to the quiz:

**Question 1:** Which of the following is the correct syntax for a link to `https://www.google.com` with the text "Search"?
**Answer:** b) `[Search](https://www.google.com)`

**Question 2:** How do you create a numbered list?
**Answer:** b) Start each line with a number and a period (e.g., `1.`).

**Question 3:** Which symbol can be used to create a bullet point in an unordered list?
**Answer:** c) `*` (You can also use `-` or `+`)
