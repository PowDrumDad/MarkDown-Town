# Lesson 6: Task Lists and Strikethrough

In this lesson, we'll learn how to create checklists to track tasks and how to use strikethrough to mark things as obsolete or completed.

## Task Lists

Task lists (or checklists) are a special kind of list in Markdown that includes checkboxes. They are incredibly useful for to-do lists, project plans, and tracking progress.

You create a task list item by starting a list item with `[ ]` (for an incomplete task) or `[x]` (for a completed task).

```markdown
- [x] Pack water testing kit
- [x] Charge GPS unit
- [ ] Collect boat keys
- [ ] Check weather forecast
```

Renders as:
- [x] Pack water testing kit
- [x] Charge GPS unit
- [ ] Collect boat keys
- [ ] Check weather forecast

In many Markdown environments (like GitHub), these checkboxes are even interactive, and you can click them to toggle their state.

## Strikethrough

Strikethrough is used to indicate that text is no longer relevant. You create it by wrapping the text in two tildes (`~~`).

```markdown
The meeting is scheduled for ~~Tuesday~~ Wednesday.
```

Renders as:
The meeting is scheduled for ~~Tuesday~~ Wednesday.
