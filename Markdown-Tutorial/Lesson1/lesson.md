# Lesson 1: The Absolute Basics

Welcome to your first lesson in the Markdown Town Tutorial! Today, we're going to learn about the fundamental building blocks of Markdown.

## What is Markdown?

Markdown is a lightweight markup language that you can use to add formatting elements to plaintext text documents. Created by John Gruber in 2004, Markdown is now one of the world’s most popular markup languages.

## Why is it useful?

- **It's simple:** The syntax is easy to learn and read.
- **It's portable:** Markdown files can be opened by any text editor.
- **It's versatile:** It can be converted into many other formats, like HTML, PDF, and more.
- **It's everywhere:** It's used for documentation on GitHub, for writing messages in chat applications like Slack and Discord, and for creating content on websites.

## Your First Mission: Headings and Paragraphs

Your first task is to create a title and an introductory paragraph for a new report.

### Headings

Headings are used to create titles and subtitles. In Markdown, you use the hash symbol (`#`) to create headings. The number of hashes indicates the heading level.

- `# Heading 1` (The main title)
- `## Heading 2` (A major section)
- `### Heading 3` (A sub-section)
- `#### Heading 4`
- `##### Heading 5`
- `###### Heading 6`

### Paragraphs

Paragraphs are just lines of text separated by a blank line.

### Bold and Italic Text

You can emphasize text by making it **bold** or *italic*.

- To make text bold, you surround it with two asterisks: `**bold text**`.
- To make text italic, you surround it with one asterisk: `*italic text*`.
