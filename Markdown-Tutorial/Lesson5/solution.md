# Lesson 5: Quiz Solutions

Here are the answers to the quiz:

**Question 1:** What character is used to separate columns in a Markdown table?
**Answer:** b) `|` (Pipe)

**Question 2:** How do you center-align a column in a Markdown table?
**Answer:** a) `|:---:|`

**Question 3:** What is the purpose of the line of hyphens (`---`) in a table?
**Answer:** b) To separate the table header from the table body.
