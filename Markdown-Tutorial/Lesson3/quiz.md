# Lesson 3: Quiz

Let's test your knowledge of images and quotes.

**Question 1:** What is the correct syntax to display an image located at `./images/photo.jpg` with the alt text "A beautiful sunset"?
a) `(A beautiful sunset)[./images/photo.jpg]`
b) `![A beautiful sunset](./images/photo.jpg)`
c) `*[A beautiful sunset](./images/photo.jpg)*`
d) `<img src="./images/photo.jpg" alt="A beautiful sunset">`

**Question 2:** What is the purpose of "alt text" for an image?
a) It's the caption displayed below the image.
b) It's a text that appears if the image fails to load and is used by screen readers.
c) It's the title of the image file.
d) It's a private comment only visible to the author.

**Question 3:** How do you create a blockquote?
a) Start the line with a `#`.
b) Surround the text with `""`.
c) Start the line with a `>`.
d) Indent the line with a tab.
