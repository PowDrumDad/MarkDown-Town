# Lesson 6: Quiz Solutions

Here are the answers to the quiz:

**Question 1:** How do you create a completed task in a task list?
**Answer:** c) `- [x] Task`

**Question 2:** What is the syntax for strikethrough text?
**Answer:** c) `~~text~~`

**Question 3:** Can you have a task list inside a numbered list?
**Answer:** a) Yes, task lists can be nested in other list types. For example:
```markdown
1. Morning Tasks
   - [x] Drink coffee
   - [ ] Check emails
2. Afternoon Tasks
   - [ ] Write report
```
