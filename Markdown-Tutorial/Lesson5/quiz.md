# Lesson 5: Quiz

Let's see if you've got the measure of tables.

**Question 1:** What character is used to separate columns in a Markdown table?
a) `,` (Comma)
b) `|` (Pipe)
c) `&` (Ampersand)
d) `;` (Semicolon)

**Question 2:** How do you center-align a column in a Markdown table?
a) `|:---:|`
b) `|---`
c) `|--:|`
d) `|:--|`

**Question 3:** What is the purpose of the line of hyphens (`---`) in a table?
a) To add a decorative border.
b) To separate the table header from the table body.
c) To indicate the end of the table.
d) To make the table responsive.
