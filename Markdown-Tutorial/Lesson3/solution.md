# Lesson 3: Quiz Solutions

Here are the answers to the quiz:

**Question 1:** What is the correct syntax to display an image located at `./images/photo.jpg` with the alt text "A beautiful sunset"?
**Answer:** b) `![A beautiful sunset](./images/photo.jpg)`

**Question 2:** What is the purpose of "alt text" for an image?
**Answer:** b) It's a text that appears if the image fails to load and is used by screen readers.

**Question 3:** How do you create a blockquote?
**Answer:** c) Start the line with a `>`.
